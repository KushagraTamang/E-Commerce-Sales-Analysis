# 📊 E-Commerce Sales Analysis Dashboard | Microsoft Excel Project

## 🔹 Project Overview
This project is an interactive **E-Commerce Sales Analysis Dashboard** created using **Microsoft Excel** to analyze sales performance, profitability, regional trends, and category-wise business insights.

The dashboard transforms raw sales data into actionable insights through KPI tracking, interactive filters, and dynamic visualizations to support data-driven decision-making.

---

## 🔹 Features
- 📈 Sales Performance Analysis
- 💰 Profit & Profit Margin Tracking
- 🌍 Region-wise Sales Insights
- 📦 Category & Sub-Category Analysis
- 🎯 KPI Monitoring Dashboard
- 🔄 Interactive Slicers & Filters
- 📊 Dynamic Charts & Visualizations

---

## 🔹 Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Reporting
- Data Cleaning & Data Analysis
- Data Visualization

---

## 🔹 KPI Metrics
- **Total Sales:** 2.29M+
- **Total Orders:** 9,993
- **Total Profit:** 539K+
- **Profit Margin:** 0.23%

---

## 🔹 Key Business Insights
- Furniture category generated high sales but low profitability due to heavy discounting
- Technology category was the most profitable across all regions
- Tables and Bookcases were identified as major loss-making sub-categories
- Overall profit margin remained low, indicating pricing or discount-related issues
- West region recorded the highest sales performance
